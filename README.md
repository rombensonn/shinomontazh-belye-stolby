# Шиномонтаж в Белых Столбах

Готовый одностраничный лендинг на `HTML5 + CSS3 + vanilla JS + PHP 8+` для шиномонтажа на ул. Дзержинского, 2 в Белых Столбах.

## Как запустить на PHP-хостинге

1. Загрузите все файлы проекта в корень сайта.
2. Убедитесь, что хостинг использует PHP 8 или новее.
3. Проверьте, что директория `storage/` недоступна из браузера. Для Apache это закрывает `storage/.htaccess`.
4. Откройте главную страницу сайта и отправьте тестовую заявку.

Для локальной проверки можно выполнить:

```bash
php -S localhost:8000
```

## Где поменять телефон, адрес и ссылки

Основные данные находятся в `includes/config.php`:

- `SITE_NAME`;
- `SITE_PHONE`;
- `SITE_PHONE_HREF`;
- `SITE_ADDRESS`;
- `YANDEX_MAPS_URL`;
- `SITE_URL`.

После смены домена обновите `SITE_URL`, `robots.txt`, `sitemap.xml` и canonical в `index.php` подтянется из конфига. Для текущей публикации GitHub Pages используется `https://rombensonn.github.io/shinomontazh-belye-stolby/`.

## GitHub Pages

В репозитории есть `index.html` — статическая сборка для GitHub Pages. GitHub Pages не выполняет PHP, поэтому публичная Pages-версия открывает лендинг, но PHP-обработчик `/api/lead.php` работает только на обычном PHP-хостинге.

## Где поменять email

В `includes/config.php`:

- `ADMIN_EMAIL` — куда отправлять заявки;
- `FROM_EMAIL` — отправитель письма;
- `ENABLE_EMAIL` — включить или выключить email-отправку.

Если `mail()` на хостинге недоступна, заявка всё равно сохраняется в `storage/leads.jsonl`.

## Как включить Telegram

В `includes/config.php` укажите:

- `TELEGRAM_BOT_TOKEN`;
- `TELEGRAM_CHAT_ID`;
- `ENABLE_TELEGRAM = true`.

Если токен не заполнен или Telegram выключен, сайт продолжит работать без ошибок.

## Права на storage

PHP должен иметь право записи в:

- `storage/leads.jsonl`;
- `storage/rate-limit.json` — создаётся автоматически при первой отправке формы.

Обычно достаточно прав `755` для папки `storage/` и `644` для файлов, но на некоторых хостингах может потребоваться другой режим.

## Как проверить форму

1. Откройте сайт.
2. Заполните имя, телефон, задачу и согласие.
3. Отправьте заявку.
4. Проверьте сообщение об успехе.
5. Откройте `storage/leads.jsonl` на сервере и убедитесь, что появилась новая строка JSON.
6. Повторная отправка раньше чем через `RATE_LIMIT_SECONDS` должна быть заблокирована.

## Фото перед запуском

Сейчас на сайте есть сгенерированные тематические кадры и нейтральные плейсхолдеры. Сгенерированные изображения подписаны как визуальные кадры и не являются реальными фото сервиса. Перед публикацией желательно добавить реальные фотографии:

- въезд / ориентир;
- рабочее место;
- шиномонтаж;
- ремонт прокола;
- колёса;
- масло / фильтр;
- колодки.

Не выдавайте плейсхолдеры за реальные фото.
