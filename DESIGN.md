# Визуальная система

Проект использует новый язык: индустриальная мастерская, тёмный металл, янтарная сигнальная разметка, срезанные панели и крупная техническая типографика.

## Принципы

- Не имитировать сетевой автосервис. Визуальный тон: небольшой частный сервис, аккуратная мастерская, прямой разговор с мастером.
- Тёмный первый экран и рабочие секции создают ощущение гаража, светлые сервисные блоки помогают быстро читать услуги.
- Янтарный цвет используется только для действия, рейтинга, направляющих линий и важных предупреждений.
- Фотографии, созданные AI, подписываются как сгенерированные тематические кадры и не выдаются за реальные фото сервиса.
- Реальные фотографии бокса, въезда и работ должны заменить плейсхолдеры перед запуском.

## Цвета

- `--coal` #08090a — основной тёмный фон.
- `--graphite` #111315 — панели и header.
- `--iron` #191c1f — вторичные тёмные поверхности.
- `--paper` #e9e0d0 — светлые рабочие секции.
- `--chalk` #f5f1e7 — основной текст на тёмном.
- `--amber` #ffb21a — главный CTA и сигнальная разметка.
- `--amber-2` #ff7a18 — глубина CTA.
- `--oxide` #b54822 — тёплый индустриальный акцент.
- `--signal` #b7ff3c — focus-visible, используется редко.

## Типографика

Глобальный шрифт — `SF Pro Display` с системными fallback: `-apple-system`, `BlinkMacSystemFont`, `SF Pro Text`, `Segoe UI`, `Roboto`, `Arial`. Заголовки плотные, uppercase, с нулевым letter-spacing. Основной текст — короткие строки, без рекламного пафоса.

## Компоненты

- Кнопки: прямоугольные, 2px radius, с механическим hover-сдвигом.
- Панели: срезанные углы через `clip-path`, тёмная стеклянно-металлическая поверхность без “глянцевых карточек”.
- Карточки услуг: тёмные media-панели с реальными/сгенерированными тематическими кадрами.
- Отзывы и FAQ: светлые читаемые блоки на фоне технической сетки.
- Мобильная CTA-панель: жёсткая нижняя панель с тремя действиями.
